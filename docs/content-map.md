# Hidden content map

**Spoilers.** This is the designer's map of every optional secret: where each
clue is, what it depends on, and what it is supposed to mean. If the repo is
public, so is this file — another reason to make it private before real clues
go in.

A clue may not depend on anything that is not written down here.

## Format

For each hidden record or code:

| Field | |
|---|---|
| **Id** | the hidden code or evidence id |
| **Where the clue is** | mission, record, page element, or external profile |
| **Prerequisites** | what the player must have seen first |
| **Depends on** | other clues it combines with |
| **Intended reading** | what a player should conclude, in one or two sentences |
| **Fallback** | the in-site copy, if the clue lives on an external platform |

## External fictional profiles

For each profile: platform, handle, the fictional identity, every post and its
purpose, which clues depend on it, and its in-site fallback record. Nothing
here exists until you create it. Accounts are made and posted by hand. They
use original fictional characters only, and never require players to contact
anyone or bypass any platform's privacy.
